# Automated-Bank-cheque-extraction

## Overview
This project automates the extraction of important information from bank cheques using OCR and Machine Learning techniques.

## Features
- Cheque image preprocessing
- OCR-based text extraction
- Automatic field identification
- Account number extraction
- IFSC code detection
- Payee name recognition
- Amount extraction

## Technologies Used
- Python
- OpenCV
- EasyOCR / Tesseract OCR
- Pandas
- NumPy
- Streamlit

## Workflow
1. Upload Cheque Image
2. Image Preprocessing
3. Text Extraction
4. Entity Recognition
5. Structured Data Output

## Extracted Information
- Account Number
- Payee Name
- Amount
- Date
- IFSC Code
- Bank Name

## Future Enhancements
- Support for multiple cheque formats
- Cloud deployment
- Improved OCR accuracy
